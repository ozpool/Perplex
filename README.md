# Perplex

Decentralised perpetual futures exchange. Orderbook-matched, USDC-collateralised, self-custodial.

Off-chain matching engine in Rust for centralised-exchange latency. On-chain settlement in Solidity on Arbitrum.

v1 markets: BTC-USD, ETH-USD, SOL-USD.

Phase 0 (local devnet bootstrap) lands in the next PR.
